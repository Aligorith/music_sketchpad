Music Sketchpad
===============

Web-based app for creating short pieces of music on the fly. The UX of this is specifically
crafted around the workflow that I like from MuseScore 3, along with a bunch of additional
things I've wished for a while (e.g. not needing to specify a time signature up front).
The design of this application is highly opinionated, and designed around personal preferences
and needs - this being of any use to anyone else will be a secondary / happy side-effect.

The first version of this was initially bashed out as a quick prototype to check whether the
approach I've had in mind for a while was feasible or not, and also to finally "get over the
hump" of having an initial version I could start playing with. Also, it just seemed like an
easier "small" project from my long backlog of projects that I could knock off during a long
public holiday weekend  :)
