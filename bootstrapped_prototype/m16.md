=======================================

Add an INS / OVR toggle that controls what happens when entering a note with an existing note selected.

- INS: Insert after the selected note, preserving the original.
- OVR: Replace the selected note.
- With no selection, both modes append at the end (or current insertion position).

## 1. Add the toggle to the HTML

Place this beside the other editing buttons, preferably before the note-name buttons:

HTMLWrap linesCopy codePreview

```html
<button id="insertMode"
        class="control-button"
        title="Toggle Insert / Overwrite">
  INS
</button>
```

## 2. Add the state variable

Near your other application state:

javascript

```javascript
let insertMode = true;
```

## 3. Add the toggle handler

javascript

```javascript
$("insertMode").onclick = () => {

  insertMode = !insertMode;

  $("insertMode").textContent =
    insertMode ? "INS" : "OVR";

  $("insertMode").style.background =
    insertMode ? "#2563eb" : "#64748b";

  $("insertMode").style.color = "#fff";
};
```

## 4. Replace `appendToken()`

javascript

```javascript
function appendToken(token) {

  saveEditor();

  const p=parts[selectedPart];
  const tokens=tokenize(p.notation);

  if(selectedNoteIndex!==null) {

    if(insertMode) {

      // Insert immediately after selected note.
      tokens.splice(
        selectedNoteIndex+1,
        0,
        token
      );

      // Select the newly inserted token.
      selectedNoteIndex++;

    } else {

      // Overwrite selected token.
      tokens[selectedNoteIndex]=token;
    }

  } else {

    // No selection: append.
    tokens.push(token);
  }

  p.notation=tokens.join(" ");

  $("notation").value=p.notation;

  renderScore();
}
```

## 5. Optional keyboard shortcut

You can also add this to your keyboard handler:

javascript

```javascript
if(key==="i" && !event.ctrlKey && !event.altKey && !event.metaKey) {

  event.preventDefault();
  $("insertMode").click();
  return;
}
```

Now pressing I toggles between INS and OVR.

Default mode: INS
