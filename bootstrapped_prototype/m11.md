```
Allow keyboard shortcuts for triggering the per-part buttons:
* a,b,c,d,e,f,g - these activate the corresponding note name
* r - adds a rest
* w - doubles length
* q - halves length
* shift-w = increases 1.5 length
* shift-q = decreases 1.5 length
* up arrow = increase semitone, down arrow = decrease semitone
* ctrl up/down = change octave
* spacebar = toggle play/stop
```

===============================

Add a keyboard shortcut handler that invokes the existing buttons' click handlers. This keeps keyboard and mouse input behaving identically, including note previews and score updates.

## 1. Add this JavaScript

Place it near the bottom of your JavaScript, before the `INITIALISE` section.

javascript

```javascript

// --------------------------------------------------
// KEYBOARD SHORTCUTS
// --------------------------------------------------

document.addEventListener("keydown", function(event) {

  // Ignore shortcuts when typing in text fields.
  const target = event.target;

  if (
    target.tagName === "TEXTAREA" ||
    target.tagName === "INPUT" ||
    target.tagName === "SELECT" ||
    target.isContentEditable
  ) {
    return;
  }

  // Avoid browser defaults for handled shortcuts.
  const key = event.key.toLowerCase();

  // Note names: A-G
  if (!event.ctrlKey && !event.altKey && !event.metaKey) {

    if ("abcdefg".includes(key) && key.length === 1) {
      event.preventDefault();

      const button = document.querySelector(
        `[data-note="${key}"]`
      );

      if(button) button.click();
      return;
    }

    // Rest
    if(key === "r") {
      event.preventDefault();
      $("restButton").click();
      return;
    }

    // Duration changes
    if(key === "w") {
      event.preventDefault();

      if(event.shiftKey) {
        $("dotUp").click();
      } else {
        $("doubleDuration").click();
      }

      return;
    }

    if(key === "q") {
      event.preventDefault();

      if(event.shiftKey) {
        $("dotDown").click();
      } else {
        $("halfDuration").click();
      }

      return;
    }

    // Semitone changes
    if(key === "arrowup") {
      event.preventDefault();
      $("semitoneUp").click();
      return;
    }

    if(key === "arrowdown") {
      event.preventDefault();
      $("semitoneDown").click();
      return;
    }

    // Playback toggle
    if(key === " ") {
      event.preventDefault();

      if(playing) {
        $("stop").click();
      } else {
        $("play").click();
      }

      return;
    }
  }

  // Octave changes: Ctrl + Up/Down
  if(event.ctrlKey && !event.altKey && !event.metaKey) {

    if(key === "arrowup") {
      event.preventDefault();
      $("octaveUp").click();
      return;
    }

    if(key === "arrowdown") {
      event.preventDefault();
      $("octaveDown").click();
      return;
    }
  }

});
```

## 2. Keyboard shortcut reference

| Shortcut | Action |
| --- | --- |
| A–G | Enter corresponding note |
| R | Enter rest |
| W | Double duration |
| Q | Halve duration |
| Shift + W | Increase duration by 1.5 |
| Shift + Q | Decrease duration by 1.5 |
| ↑ | Raise last note by semitone |
| ↓ | Lower last note by semitone |
| Ctrl + ↑ | Raise last note an octave |
| Ctrl + ↓ | Lower last note an octave |
| Space | Toggle playback |

## 3. Small usability detail

The handler deliberately ignores keyboard shortcuts while editing the LilyPond textbox, part name, tempo, or other input fields. This prevents accidental note entry while typing notation.

It also uses the existing buttons, so the keyboard shortcuts automatically inherit the current editing duration, selected instrument, accidental handling and audio previews.
