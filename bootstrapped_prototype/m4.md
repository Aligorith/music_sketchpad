```
When updating the last note, a preview of the updated pitch (when updating semitones) should be played
```

========================================

Modify `updateLastNote()` so that it plays the new pitch whenever a semitone or octave adjustment is made.

Replace your existing function with:

javascript

```javascript
function updateLastNote(transform) {

  const p=parts[selectedPart];
  const tokens=tokenize(p.notation);

  const index=lastNoteIndex();

  if(index<0) return;

  const token=parseToken(tokens[index]);
  const info=pitchInfo(token,{});

  if(!info) return;

  const newMidi=transform(info.pitch);

  const names=[
    "c","cis","d","dis","e","f",
    "fis","g","gis","a","ais","b"
  ];

  const pc=((newMidi%12)+12)%12;
  const octave=Math.floor(newMidi/12)-1;

  const relative=octave-3;

  const marks=relative>0?
    "'".repeat(relative):
    ",".repeat(-relative);

  const newPitch=names[pc]+marks;

  // Preserve duration and dotted rhythm.
  tokens[index]=
    newPitch+
    token.duration+
    (token.dotted?".":"");

  p.notation=tokens.join(" ");

  $("notation").value=p.notation;

  renderScore();

  // Preview the updated pitch using the selected instrument.
  previewPitch(newPitch);
}
```

This automatically covers all four controls:

- Octave up
- Octave down
- Semitone up
- Semitone down

The preview uses the selected part's instrument and volume, and plays for one crotchet regardless of the edited note's actual duration.
