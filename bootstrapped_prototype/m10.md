===============================

I'd restructure the page into three main areas:

1. Compact header: App name, tempo, playback marker, Play and Stop.
2. Large score: Takes up most of the available screen height and width.
3. Compact editor panel: Part selector/settings, LilyPond textbox, and tightly arranged note-entry controls.

The note buttons will use a compact grid, with the paired controls vertically stacked.

## 4. One JavaScript adjustment

Your existing JavaScript can mostly remain unchanged.

However, `renderScore()` currently calculates the width using:

javascript

```javascript
const width=Math.max(950,window.innerWidth-90);
```

That forces a 950px minimum, which is inconvenient on phones.

Replace it with:

javascript

```javascript
const width=Math.max(
  500,
  $("scoreScroll").clientWidth-16
);
```

Also change the height calculation to:

javascript

```javascript
const height=Math.max(
  140,
  parts.length*150+20
);
```
