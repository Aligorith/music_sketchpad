```
Note entry into lilypond and subsequent playback are dropping the accidental
```

=================================

The problem is that the current `appendPitch()` and `updateLastNote()` implementations are not consistently preserving the effective accidental. In particular, `pitchInfo(token,{})` forgets previous accidental state, and `midiToLily()` can generate a sharp or flat without ensuring that the playback parser interprets it correctly.

I'd fix this in three places.

## 1. Add a shared accidental-aware pitch formatter

Add this helper near `midiToLily()`:

javascript

```javascript

function midiToLilyWithAccidental(midi) {

  const names = [
    ["c",""],
    ["d","es"],
    ["d",""],
    ["e","es"],
    ["e",""],
    ["f",""],
    ["g","es"],
    ["g",""],
    ["a","es"],
    ["a",""],
    ["b","es"],
    ["b",""]
  ];

  const pc = ((midi % 12) + 12) % 12;
  const octave = Math.floor(midi / 12) - 1;
  const relative = octave - 3;

  const marks = relative > 0
    ? "'".repeat(relative)
    : ",".repeat(-relative);

  const [letter, accidental] = names[pc];

  return letter + accidental + marks;
}
```

This uses flats for black notes, avoiding ambiguity between enharmonic spellings.

## 2. Replace `appendPitch()`

This version finds the previous pitch, selects the nearest octave, and preserves an accidental that is already active for that pitch.

javascript

```javascript

function appendPitch(letter) {

  const tokens = tokenize(
    parts[selectedPart].notation
  );

  let lastPitch = null;

  // Find the last pitched note.
  for(let i=tokens.length-1;i>=0;i--) {

    if(tokens[i] === "|" || /^r/.test(tokens[i])) {
      continue;
    }

    try {
      const token = parseToken(tokens[i]);
      const info = pitchInfo(token,{});

      if(info) {
        lastPitch = info;
        break;
      }
    } catch(e) {}
  }

  const semitones = {
    c:0,d:2,e:4,f:5,g:7,a:9,b:11
  };

  let octave = 3;

  if(lastPitch) {

    const candidates = [];

    for(let o=lastPitch.octave-1;
        o<=lastPitch.octave+1;o++) {

      const midi = 12*(o+1)+semitones[letter];

      candidates.push({
        octave:o,
        pitch:midi
      });
    }

    candidates.sort((a,b)=>
      Math.abs(a.pitch-lastPitch.pitch) -
      Math.abs(b.pitch-lastPitch.pitch)
    );

    octave = candidates[0].octave;
  }

  const state = getAccidentalState();

  const key = letter+":"+octave;

  const accidental = state[key] || "";

  const marks = octave>3
    ? "'".repeat(octave-3)
    : ",".repeat(3-octave);

  const pitch = letter+accidental+marks;

  previewPitch(pitch);

  appendToken(
    pitch+durationText(currentDuration)
  );
}
```

## 3. Add this accidental-state helper

This reconstructs the accidental state from the existing notation, including explicit barline resets.

javascript

```javascript

function getAccidentalState() {

  const state = {};

  const tokens = tokenize(
    parts[selectedPart].notation
  );

  for(const raw of tokens) {

    const token = parseToken(raw);

    if(token.bar) {

      Object.keys(state).forEach(
        key => delete state[key]
      );

      continue;
    }

    if(token.rest) continue;

    pitchInfo(token,state);
  }

  return state;
}
```

## 4. Replace `updateLastNote()`

This ensures that semitone changes are written as explicit LilyPond accidentals and that playback uses the resulting pitch.

javascript

```javascript

function updateLastNote(transform) {

  const p = parts[selectedPart];
  const tokens = tokenize(p.notation);

  const index = lastNoteIndex();

  if(index < 0) return;

  const token = parseToken(tokens[index]);

  const state = getAccidentalState();

  const info = pitchInfo(token,state);

  if(!info) return;

  const newMidi = transform(info.pitch);

  const newPitch = midiToLilyWithAccidental(newMidi);

  tokens[index] =
    newPitch+
    token.duration+
    (token.dotted?".":"");

  p.notation = tokens.join(" ");

  $("notation").value = p.notation;

  renderScore();

  // Preview the actual updated pitch.
  previewPitch(newPitch);
}
```

## Expected results

| Action | LilyPond notation | Playback |
| --- | --- | --- |
| Enter F | `f'4` | F natural |
| Raise F by semitone | `fis'4` | F sharp |
| Enter F again | `fis'4` | F sharp |
| Enter B and lower semitone | `bes'4` | B flat |
| Enter B again | `bes'4` | B flat |
| Insert \` | \`, then enter F | `f'4` \| F natural |

Important: This fixes accidental persistence for the note-entry and pitch-editing paths. It also relies on `parsePart()` retaining its existing accidental-state logic for playback.

One additional improvement I'd recommend is changing the playback parser to use the same shared accidental-state logic as the score renderer, so that notation, displayed score and audio can never disagree.
