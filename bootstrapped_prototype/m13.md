Let's make the insert-head follow the selected note, appearing immediately after it, and make the current part name stand out inside the score itself.

## 1. Add a helper to calculate the insert position

Add this function near your selection helpers:

javascript

```javascript
function getInsertBeat() {

  if(selectedNoteIndex!==null) {

    const events=parsePart(parts[selectedPart]);

    const selected=events.find(
      e=>e.tokenIndex===selectedNoteIndex
    );

    if(selected) {
      return selected.beat+selected.beats;
    }
  }

  return totalBeatsForPart(selectedPart);
}

function totalBeatsForPart(index) {

  return parsePart(parts[index]).reduce(
    (sum,e)=>sum+(e.bar?0:e.beats),
    0
  );
}
```

## 2. Draw the insert-head at the correct position

In `renderScore()`, remove the old insert-head code that places it after the final note.

Replace it with:

javascript

```javascript
// --------------------------------------------------
// INSERT-HEAD POSITION
// --------------------------------------------------

const insertBeat=getInsertBeat();

let insertX=stave.getNoteStartX();

// Find the horizontal position immediately after
// the selected note, or at the end if none selected.

if(selectedNoteIndex!==null) {

  const selected=tickables.find(
    n=>n._tokenIndex===selectedNoteIndex
  );

  if(selected) {
    insertX=selected.getAbsoluteX()+
            selected.getWidth()+5;
  }

} else if(tickables.length) {

  const last=tickables[tickables.length-1];

  insertX=last.getAbsoluteX()+
          last.getWidth()+5;
}

const ns="http://www.w3.org/2000/svg";
const svg=output.querySelector("svg");

if(svg) {

  const line=document.createElementNS(ns,"line");

  line.setAttribute("x1",insertX);
  line.setAttribute("x2",insertX);
  line.setAttribute("y1",y);
  line.setAttribute("y2",y+100);

  line.setAttribute("stroke","#2563eb");
  line.setAttribute("stroke-width","2");
  line.setAttribute("stroke-dasharray","4 3");

  line.setAttribute("class","insert-head");

  svg.appendChild(line);
}
```

This positions the cursor immediately after the selected note.

context.save();

## 5. One important correction for insertion

Currently your `appendToken()` replaces the selected note. If you want the insert-head to mean that subsequent note entry happens after the selected note, rather than replacing it, replace `appendToken()` with:

javascript

```javascript
function appendToken(token) {

  saveEditor();

  const p=parts[selectedPart];
  const tokens=tokenize(p.notation);

  if(selectedNoteIndex!==null) {

    tokens.splice(
      selectedNoteIndex+1,
      0,
      token
    );

    selectedNoteIndex++;

  } else {

    tokens.push(token);
  }

  p.notation=tokens.join(" ");

  $("notation").value=p.notation;

  renderScore();
}
```

This gives you a more natural editing workflow:

1. Click a note.
2. The note highlights blue.
3. The insert-head appears immediately after it.
4. Press C, D, E, etc.
5. The new note is inserted after the selected note.
6. The insert-head moves after the newly inserted note.

The selected-note editing controls (semitone, octave and duration) can still modify the selected note directly.

Important: With this last change, the selection should remain on the original note when inserting, rather than incrementing `selectedNoteIndex`. Remove the `selectedNoteIndex++` line if you want the original note to remain selected and the insert-head to stay after the newly inserted note; alternatively, select the newly inserted note if you prefer the cursor to follow it.
