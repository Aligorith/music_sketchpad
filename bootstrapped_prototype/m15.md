All staves should adjust accordingly when extra notes are added in one, so that they all stay aligned

======================================

The score needs a shared horizontal time axis. At the moment, each part is formatted independently, so adding a note to one part changes its spacing without changing the others.

The solution is to calculate the horizontal position of every rhythmic event across all parts, then use those same positions when drawing every stave.

This also means rests and barlines will stay vertically aligned.

## 1. Add a shared timeline function

Add this before `renderScore()`:

javascript

```javascript

// --------------------------------------------------
// SHARED SCORE TIMELINE
// --------------------------------------------------

function buildSharedTimeline() {

  const allEvents=parts.map(part=>parsePart(part));

  const positions=new Set([0]);

  allEvents.forEach(events=> {

    events.forEach(event=> {

      positions.add(event.beat);

      if(!event.bar) {
        positions.add(event.beat+event.beats);
      }

    });

  });

  const beats=[...positions].sort((a,b)=>a-b);

  const maxBeat=Math.max(0,...beats);

  return {
    allEvents,
    beats,
    maxBeat
  };
}

// Convert a beat position into a common horizontal position.
function beatToX(beat,timeline,stave) {

  const left=stave.getNoteStartX();
  const right=stave.getX()+stave.getWidth()-20;

  const available=right-left;

  if(timeline.maxBeat===0) return left;

  return left+(beat/timeline.maxBeat)*available;
}
```

## 2. Replace the independent voice formatting in `renderScore()`

The important change is to stop using:

javascript

```javascript
new VF.Formatter()
  .joinVoices([voice])
  .format([voice],width-170);
```

Instead, use a shared horizontal position for every event.

Replace the note-rendering section inside your `parts.forEach()` loop with the following:

javascript

```javascript

const timeline=buildSharedTimeline();

// Each part uses exactly the same time-to-X mapping.
const events=timeline.allEvents[index];

const tickables=[];

events.forEach(event=> {

  if(event.bar) {

    const bar=new VF.BarNote(
      VF.Barline.type.SINGLE
    );

    bar._tokenIndex=event.tokenIndex;
    bar._beat=event.beat;

    tickables.push(bar);

    return;
  }

  let note;

  if(event.rest) {

    note=new VF.StaveNote({
      keys:["b/4"],
      duration:durationCode(event)+"r",
      clef:"treble"
    });

  } else {

    note=new VF.StaveNote({
      keys:[event.letter+"/"+event.octave],
      duration:durationCode(event),
      clef:"treble"
    });

    if(event.accidental) {

      note.addModifier(
        new VF.Accidental(
          event.accidental==="is" ? "#" :
          event.accidental==="es" ? "b" : "n"
        ),
        0
      );
    }
  }

  note._tokenIndex=event.tokenIndex;
  note._beat=event.beat;

  tickables.push(note);

});

// Draw stave.
stave.setContext(context).draw();

// Position all notes using the shared timeline.
tickables.forEach(note=> {

  const x=beatToX(
    note._beat,
    timeline,
    stave
  );

  note.setX(x);
  note.setContext(context);

  note.draw();
});
```

Important: This is a positioning approach rather than a complete replacement for VexFlow's formatter. `setX()` and drawing individual tickables may not be supported consistently across VexFlow versions. For reliable rendering, I recommend the formatter-based approach below instead.

## 3. Recommended: use a common formatter width

A safer solution is to give all parts the same number of ticks and format them together.

Instead of formatting each part separately, construct all voices first, then use a single `VF.Formatter`:

javascript

```javascript
const formatter=new VF.Formatter();

formatter.joinVoices(allVoices);

formatter.format(
  allVoices,
  width-170
);

allVoices.forEach((voice,index)=> {
  voice.draw(context,staves[index]);
});
```

This makes VexFlow distribute the rhythmic positions consistently across all parts.

You will need to pad shorter parts with invisible notes or rests so all voices have the same total duration.

## 4. Handle the insertion cursor

The insertion cursor should also use the shared timeline:

javascript

```javascript
const insertX=beatToX(
  getInsertBeat(),
  timeline,
  stave
);
```

This ensures the cursor lines up with the same rhythmic position on every stave.
