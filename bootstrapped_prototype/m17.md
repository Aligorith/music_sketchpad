=========================================

I'd add the time and key signatures as global score settings, rather than per-part settings. They'll appear in the header and apply consistently to every stave.

There are three changes:

1. Time signature: configurable numerator and denominator, defaulting to 4/4.
2. Key signature: selectable major/minor key, displayed after the treble clef.
3. Beaming: notes grouped according to the selected time signature, with correct stem direction and beam placement.

For beaming, use VexFlow's automatic stem and beam calculations rather than manually drawing beam slopes. This is important for notes above and below the middle of the stave.

Add the following functions:

function updateMusicalSettings() {

  const [n,d]=$("timeSignature").value
    .split("/")
    .map(Number);

  timeSignature={
    numerator:n,
    denominator:d
  };

  keySignature=$("keySignature").value;

  renderScore();
}

Register the controls:

## 4. Make voice timing use the selected time signature

Where you currently construct the voice:

javascript

```javascript
const voice=new VF.Voice({
  num_beats:Math.max(1,Math.ceil(beats)),
  beat_value:4
});
```

Replace it with:

javascript

```javascript
const voice=new VF.Voice({
  num_beats:Math.max(
    1,
    Math.ceil(
      beats*timeSignature.denominator/4
    )
  ),
  beat_value:timeSignature.denominator
});

voice.setStrict(false);
```

This makes the voice's beat structure correspond to the selected denominator.

## 5. Add time-signature-aware beaming

Add this helper before `renderScore()`:

javascript

```javascript
// --------------------------------------------------
// BEAM GROUPING
// --------------------------------------------------

function getBeamGroups() {

  const n=timeSignature.numerator;
  const d=timeSignature.denominator;

  // Compound time: groups of three denominator units.
  if(d===8 && n>=6 && n%3===0) {

    return Array.from(
      {length:n/3},
      ()=>new VF.Fraction(3,8)
    );
  }

  // Simple time: groups of one quarter note.
  if(d===4) {

    return Array.from(
      {length:n},
      ()=>new VF.Fraction(1,4)
    );
  }

  // Half-note beat.
  if(d===2) {

    return Array.from(
      {length:n},
      ()=>new VF.Fraction(1,2)
    );
  }

  // Other meters: group according to denominator beat.
  return Array.from(
    {length:n},
    ()=>new VF.Fraction(1,d)
  );
}
```

After creating the `tickables` array, but before drawing the voice, generate beams:

javascript

```javascript
const beams=VF.Beam.generateBeams(
  tickables,
  {
    groups:getBeamGroups(),
    beam_rests:false,
    maintain_stem_directions:false
  }
);
```

Then, after:

javascript

```javascript
voice.draw(context,stave);
```

add:

javascript

```javascript
beams.forEach(beam=> {
  beam.setContext(context).draw();
});
```

VexFlow's beam generation uses the notes' stem positions to calculate beam slopes, rather than drawing every beam horizontally.

### Important about stem direction

For the automatically calculated stem directions, add this immediately after creating each pitched `StaveNote`:

javascript

```javascript
note.autoStem();
```

For example:

javascript

```javascript
const note=new VF.StaveNote({
  keys:[event.letter+"/"+event.octave],
  duration:
    durationCode(event)+
    (event.dotted?"d":""),
  clef:"treble"
});

note.autoStem();
```

This lets notes above and below the staff's middle line use appropriate stem directions. The beam generator can then calculate the beam angle from those stems.

## 6. Make playback respect the time signature

Your playback currently treats a crotchet as one beat. That is fine internally, provided the tempo is interpreted as crotchet BPM.

Keep:

javascript

```javascript
const seconds=60/bpm;
```

For example, 6/8 at 100 BPM will mean 100 crotchets per minute, not 100 dotted crotchets per minute. This is a useful convention to keep consistent.
